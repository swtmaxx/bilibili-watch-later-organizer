# 更新计划

目标：先把发布和现有使用流程补齐，再投入数据与交互改造较大的功能。每项上线时都保持手动确认的视频分类不被自动流程覆盖。

## 近期（按顺序）

1. **Release 提供压缩包（已完成：v1.1.0）**
   - 固定发布检查清单：更新版本号、打包扩展源码、在 Release 附上 ZIP，并说明解压后如何在浏览器中重新加载。
   - 保持 ZIP 只包含加载扩展所需文件，排除 `.git`、测试和本地代理配置。

2. **Edge 浏览器语言适配（已完成：v1.1.0）**
   - 核对 Edge 的语言环境与扩展显示文案；让界面能够正确跟随浏览器语言设置，为后续英文界面预留文案结构。
   - 这一阶段只解决 Edge 兼容与语言读取，不一次性翻译全部界面。

3. **在“编辑分类目录”中加入自动更新入口（已完成：v1.1.1）**
   - 在分类目录编辑区域提供清晰入口，用于让 AI 生成或替换分类目录。
   - 当前仅保留 API 生成入口；入口和说明明确：它调整的是“分类目录”，不是给已有视频重新分类。替换前展示确认提示，且不覆盖手动确认的视频分类。
   - 分类目录生成与 API 批量视频分类共用可折叠“设置”中的 API 配置，并提供 API 测试；两者合并在同一张卡片中。

4. **自动 API 视频分类选项（已完成：v1.1.3）**
   - “设置”中的 API 设置与自动分类设置分别折叠；分类目录和视频分类中的入口统一使用“设置API”，缺少配置或调用失败时自动展开 API 设置。
   - 自动分类支持关闭、每天、每周，或待精细分类达到指定数量时触发，并显示上次运行时间和结果。
   - 后台按批次处理待精细分类，较大任务会稍后继续；所有自动流程继续跳过手动确认。

5. **视频进度（已完成：v1.1.2）**
   - 已从稍后再看列表缓存视频时长、已看时长、是否看完状态和观看次数；旧缓存会在下次同步时补齐，接口缺少字段时保持降级显示。
   - 视频卡片封面左下角显示观看次数，右下角在有进度时显示“已看/总时长”，封面底部显示黑底粉红细进度条。

6. **分类顺序拖动优化（已完成：v1.1.2）**
   - 同级分类继续限制在同一层移动；拖动任一分类时，它和全部子分类作为一个整体，并提供前后落点指示。
   - 拖动期间支持滚轮滚动分类目录；放下后只保存顺序并刷新本地界面，不自动同步视频或重新分类。

## 远期目标

1. **支持 YouTube 稍后再看**：抽象视频来源与同步层，再为 YouTube 单独实现授权、列表同步、进度和跳转；不与 B站数据混淆。
2. **完整英语支持**：在 Edge 语言适配基础上，完成可见界面、首次引导、错误提示和 README 的中英文文案。
3. **历史总结**：基于观看、分类和进度数据提供时间范围总结；先定义本地数据口径和隐私说明，再设计摘要形式。
4. **B站评论区地址入口**：在评论区识别或提供地址快捷入口，先评估页面结构稳定性、误触风险和隐私影响。

## 建议的版本节奏

- **1.1.0**：发布 ZIP 与 Edge 语言适配。
- **1.1.1**：分类目录自动更新入口。
- **1.1.2**：视频进度与分类顺序拖动优化。
- **1.1.3**：设置层级与自动 API 视频分类。
