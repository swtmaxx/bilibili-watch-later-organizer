# 稍后再看整理助手

当前版本：1.1.28

这是一个给屯屯鼠准备的 B站稍后再看分类插件。它会把越攒越多的稍后再看视频整理成清晰的分类目录，让你更快找到真正想看的内容，而不是继续在长长的列表里翻找。

插件可以先在本地完成快速的初步分类，也支持使用 AI 进一步批量分类，以及手动确认重要视频。手动确认的结果优先级最高，不会被后续的自动分类覆盖。

![分类管理界面](docs/category-management.png)

## 主要功能

- 同步 B站稍后再看列表，并补充视频标题、UP 主、分区等信息。
- 按分类目录或按 UP 主浏览、搜索和筛选视频。
- 支持在卡片视图和列表视图之间切换，并记住上次选择。
- 卡片按播放量、点赞数、评论数、收藏数、投币数、弹幕数、转发数和点赞率显示统计信息。
- 在本地进行初步分类，不需要配置 API。
- 使用 OpenAI-compatible API 进行 AI 批量视频分类。
- 导出和导入本地数据备份，迁移分类目录、视频信息、分类结果和设置。
- 单个或批量手动调整视频分类。
- 在批量管理中创建 B站私密收藏夹，并将选中视频批量加入。
- 从稍后再看中移出不需要的视频，支持批量移出并保留本地分类记录。

## 安装

目前请通过“加载已解压的扩展程序”安装：

1. 在 GitHub 的 Releases 页面下载最新的 `bili-watchlater-organizer-edge-*.zip`，并解压到一个固定文件夹。不要直接选择 ZIP 文件，也不要选择解压后外层的空文件夹。
2. 在 Chrome 中打开 `chrome://extensions/`，或在 Edge 中打开 `edge://extensions/`。
3. 开启页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目文件夹。
5. 登录 B站，然后点击浏览器工具栏中的插件图标。

### 从 Release 更新并重新加载

1. 下载新版本 ZIP 并解压。
2. 用解压后的文件替换当前已加载扩展文件夹中的内容；替换后该文件夹的第一层应直接包含 `manifest.json`、`src`、`icons` 和 `_locales`。
3. 回到 `chrome://extensions/` 或 `edge://extensions/`，在“稍后再看整理助手”卡片上点击“重新加载”。
4. 如果浏览器提示找不到扩展文件夹，请点击“加载已解压的扩展程序”，重新选择包含 `manifest.json` 的文件夹。

不要随意移动或删除当前已加载的扩展文件夹，否则浏览器将无法继续加载插件。

## 首次使用

首次打开“稍后再看整理助手”后，按页面引导完成以下设置：

1. 确认当前浏览器已登录 B站，插件会同步你的稍后再看列表。
2. 设置分类目录。你可以直接使用默认目录、手动编辑目录，或使用 API 让 AI 生成目录；样本数量在“让 AI 生成分类目录”区域设置。生成目录时，AI 会参考抽样视频的标题、UP 主、分区、标签、简介、分P标题和时长，不会因此给视频分类。
3. 选择整理方式：手动调整视频分类，或使用“AI (API) 批量视频分类”。

分类目录决定“有哪些分类”；视频分类决定“每个视频放在哪里”。生成或编辑分类目录不会自动完成全部视频的 AI 分类。

插件中的分类分为三种：

- **初步分类**：插件根据标题、分区等信息在本地快速判断，适合先把大量视频粗略整理起来。
- **AI 分类**：AI 阅读视频信息后进行更细致的判断。
- **手动确认**：由你亲自保存，优先级最高，不会被自动流程覆盖。

## 日常使用

点击浏览器工具栏图标，或点击 B站首页右侧的蓝色圆形入口，即可打开整理助手。

- 左侧可以切换“按分类目录”和“按 UP 主”两种浏览模式：前者浏览分类目录，后者按 UP 主分组；有多个视频的 UP 主分别成组，只有一个视频的 UP 主会合并到“单视频 UP 主”组，分组数量只统计当前仍在稍后再看的视频。浏览模式只改变浏览和筛选方式，不会新增视频分类来源，也不会改变分类目录或手动确认结果。
- 分类目录中有子分类的一级分类可以用右侧箭头折叠或展开；折叠只影响目录显示，不会改变视频分类结果。
- 可以按视频时长的常用区间或自定义范围，以及观看进度筛选视频；没有有效时长的视频单独归入“时长未知”。
- 视频区支持“卡片视图”和“列表视图”，只改变排列方式，不影响筛选、排序、分类或批量操作。
- “待精细分类”会集中显示只有初步分类、结果过旧、结果不确定或分类异常的视频。
- 顶部“同步并更新”用于获取最新的稍后再看列表和缺失的视频信息。
- 点击视频封面可打开普通视频页；点击“稍后合集中打开”可进入 B站稍后再看播放上下文。
- 点击视频卡片可展开“手动调整视频分类”。
- 点击视频卡片上的删除图标，可在确认后请求 B站接口移出稍后再看；遇到 B站来源校验时，插件会在后台临时使用 B站页面上下文重试，不需要手动打开页面。

## 批量管理

需要一次整理多个视频时：

1. 在右侧“手动调整视频分类”中点击“批量管理”。
2. 点击视频卡片逐个选择，或在视频区域拖拽框选多个视频。
3. 选择要添加、移除或替换的分类。
4. 确认批量操作并保存。

“新建收藏夹”面板会复用当前已选择的视频。输入名称后，每次操作都会在 B站创建一个新的私密收藏夹并逐个加入视频；缺少视频编号、重复选择或接口失败的项目会在完成后汇总显示。此操作使用当前 B站登录状态，不会把视频信息发送给 AI。

“批量移出稍后再看”会在确认后逐个请求 B站接口移出选中视频；遇到 B站来源校验时，插件会在后台临时使用 B站页面上下文重试，不需要手动打开页面。本地视频记录、分类结果和手动确认会保留。失败的视频会继续保留在选择中，方便修正后重试。

**AI (API) 批量视频分类**：先在可折叠的“设置”中填写并测试 API URL、接口格式、模型和 API Key，再设置每批数量后直接运行。AI 会参考视频信息和分类目录关键词；缺失的 UP 主或分P信息会先排队补充。接口格式支持 Chat Completions (`/v1/chat/completions`) 和 Responses (`/v1/responses`)；分类目录生成共用这组配置，配置保存在扩展本地存储中。

“设置”中的 API 设置和自动 API 视频分类设置可以分别折叠。自动分类支持关闭、每天、每周，或在待精细分类达到指定数量时触发；数量模式会在打开或刷新整理助手，以及点击“同步并更新”后检查一次，浏览器需要保持运行。

批量自动分类会跳过手动确认的视频，失败的批次也不会清空已经成功保存的结果。

## 数据备份

在右侧“设置”中的“数据备份”可以导出本地数据 JSON 文件，也可以选择备份文件导入。导入会合并视频记录并应用备份中的分类目录、分类结果和设置；已有手动确认不会被覆盖，导入中的运行任务会恢复为待处理状态。

备份文件包含 API Key。请把它当作敏感文件保存，不要提交到 Git 或上传到公开位置。

## 数据与隐私

- 视频信息、分类结果和处理队列保存在扩展自己的 IndexedDB 中。
- 设置、分类目录和 AI API 配置保存在 `chrome.storage.local` 中。
- 插件不会保存 B站 Cookie，不会上传浏览历史，也不会保存视频封面文件。
- 初步分类完全在本地运行，不调用外部 AI 服务。
- 只有在你主动使用 AI 分类，或明确开启自动 API 视频分类后，所选 API 服务才会收到分类所需的视频文本信息。
- 使用“新建收藏夹”时，插件会向 B站收藏接口提交收藏夹名称和选中视频的 `aid`；收藏夹默认私密，不会发送给 AI 服务。
- 卸载插件通常会同时删除扩展本地数据，请在卸载前自行确认是否需要保留重要设置。

## 使用提示

- 如果同步失败，请先确认当前浏览器已登录 B站，再重新打开整理助手。
- 如果 AI 分类失败，请检查 API URL、模型名称、API Key 和服务余额。
- 不同 AI 服务对 JSON 输出格式的支持不同；遇到兼容问题时，可以关闭“请求结构化 JSON 输出”后重试。Responses 接口会使用对应的 `text.format` 参数。
- 本项目与哔哩哔哩官方无关，B站页面或接口变化可能影响部分功能。
